# Auto Alternative Terminals / 自动备用站台

作者：spy · 版本：v1 · 模组 ID：`spy_auto_alternative_terminals`

在线路中新增停靠站时，按住触发键点击车站，就会自动勾选备用站台；普通点击照常添加站点。新建线路的第一站、末尾添加和中途插入都支持。

## 使用方式

默认触发键为 **Ctrl**。可以在模组选项中改为 Shift 或 Alt。Ctrl、Shift、Alt 分别对应游戏中的“次要模式”“精确模式”“表面吸附”动作。如果改过这些动作的键位，请使用修改后的按键。更改模组选项后需重新加载游戏。Shift 在线路编辑器中还会优先添加途经点，建议使用 Ctrl。

## 选择范围

模组会选择同一车站内除主站台外的站台。部分站台可能无法从当前线路到达；如出现路径警告，请取消勾选不合适的站台。

游戏选定的主站台、自动勾选的货物和装载设置会保留。模组只处理新添加的站点，不改动已有站点。之后可以手动取消备用站台，后续编辑也不会重新勾选。

## 安装与存档

本模组不依赖其他模组，已有存档也可直接启用。移除模组后，不会再自动勾选备用站台；此前保存的设置仍会保留。
