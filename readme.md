# Auto Alternative Terminals / 自动备用站台

作者：spy · 版本：v1 · 模组 ID：`spy_auto_alternative_terminals`

按住触发键创建线路或新增停靠站时，自动勾选同站组的备用站台；普通点击保持原版行为。

## 使用方式

默认按住 **Ctrl** 再点击要新增的车站，才自动选择备用站台。不按触发键时完全按原版方式处理。

模组参数“自动备用触发键”可选择：Ctrl（绑定次要模式键）、Shift（绑定精确模式键）或Alt（绑定表面吸附键）。实际按键遵循游戏对应动作的绑定，修改选项后重新加载游戏。Shift 在原版线路编辑器中还有优先添加途经点的作用，建议使用默认 Ctrl。

新建线路的第一站、末尾新增和中间插入均支持，同一车站也可以在一条线路中多次停靠。

三项对本模组的效果完全相同，区别仅在触发键。Ctrl、Shift、Alt 是默认键位；若在游戏设置中更改了对应动作的绑定，请使用修改后的按键。

## 功能特点

- 保留原版确定的主站台。
- 保留原版装载物品自动勾选和装载配置。
- 只为新添加的停靠站设置默认备用列表，不批量修改已有站点。
- 可以手动取消不需要的备用站台，后续编辑不会强制恢复。

## 站台选择范围

按照原版备用站台选择条件，选择同一站组中除主站台以外的站台。自动勾选不代表所有候选站台都能在当前线路上到达；复杂站组出现路径警告时，请手动取消不合适的备用站台。

## 存档与移除

可以为已有存档启用模组，启用前的停靠站保持原设置。移除模组后不再自动勾选，已经保存在原版线路配置中的备用站台仍会保留。

这是纯脚本模组，不需要其他模组作为依赖。
