中文说明

在线路中新增停靠站时，按住触发键点击车站，就会自动勾选备用站台；普通点击照常添加站点。新建线路的第一站、末尾添加和中途插入都支持。

使用方式

默认触发键为 Ctrl。可以在模组选项中改为 Shift 或 Alt。Ctrl、Shift、Alt 分别对应游戏中的“次要模式”“精确模式”“表面吸附”动作。如果改过这些动作的键位，请使用修改后的按键。更改模组选项后需重新加载游戏。Shift 在线路编辑器中还会优先添加途经点，建议使用 Ctrl。

选择范围

模组会选择同一车站内除主站台外的站台。部分站台可能无法从当前线路到达；如出现路径警告，请取消勾选不合适的站台。

游戏选定的主站台、自动勾选的货物和装载设置会保留。模组只处理新添加的站点，不改动已有站点。之后可以手动取消备用站台，后续编辑也不会重新勾选。

安装与存档

本模组不依赖其他模组，已有存档也可直接启用。移除模组后，不会再自动勾选备用站台；此前保存的设置仍会保留。

English

Hold the activation key while clicking a station to add a stop, and the mod selects its alternative terminals. A regular click adds the stop normally. This works for the first stop on a new line, stops added at the end, and stops inserted between others.

How to use

Ctrl is the default. You can choose Shift or Alt in the mod options. Ctrl, Shift, and Alt correspond to the game's Secondary Mode, Precision Mode, and Surface Snapping actions, respectively. If you've remapped one of those actions, use its new key. Reload the game after changing the mod option. Shift also prioritizes adding a waypoint in the line editor, so Ctrl is recommended.

Terminal selection

The mod selects other terminals at the same station, excluding the primary terminal. Some may not be reachable on the current line. If you see a path warning, deselect the unsuitable terminals.

The game's selected primary terminal, cargo selections, and loading settings remain unchanged. Only the new stop gets alternatives; existing stops stay as they are. You can deselect alternatives later, and editing the line won't select them again.

Installation and saves

This mod does not depend on any other mods and works with existing saves. Removing it stops automatic selection; previously saved alternatives remain.

Français

Lorsque vous ajoutez un arrêt à une ligne, maintenez la touche choisie enfoncée et cliquez sur la station : les terminaux alternatifs sont alors sélectionnés automatiquement. Un clic normal ajoute l'arrêt comme d'habitude. Cela fonctionne pour le premier arrêt d'une nouvelle ligne, pour un arrêt ajouté à la fin ou inséré entre deux arrêts.

Utilisation

La touche par défaut est Ctrl. Vous pouvez choisir Maj (Shift) ou Alt dans les options du mod. Ctrl, Maj et Alt correspondent respectivement aux actions « mode secondaire », « mode précision » et « accrochage aux surfaces » du jeu. Si vous avez modifié le raccourci d'une de ces actions, utilisez la nouvelle touche. Rechargez le jeu après avoir changé cette option. Dans l'éditeur de lignes, Maj privilégie aussi l'ajout de points de passage ; Ctrl est donc recommandé.

Choix des terminaux

Le mod sélectionne les autres terminaux de la même station, à l'exception du terminal principal. Certains peuvent être inaccessibles sur la ligne actuelle. Si un avertissement d'itinéraire apparaît, désélectionnez les terminaux concernés.

Le terminal principal, la sélection du fret et les paramètres de chargement définis par le jeu restent inchangés. Le mod ne modifie que le nouvel arrêt, sans toucher aux arrêts existants. Vous pouvez ensuite retirer des terminaux alternatifs ; ils ne seront pas sélectionnés à nouveau lors d'une modification ultérieure de la ligne.

Installation et sauvegardes

Ce mod ne dépend d'aucun autre mod et peut être activé dans une partie déjà commencée. Si vous le désinstallez, la sélection automatique s'arrête ; les terminaux alternatifs déjà enregistrés restent en place.
