中文 · 自动备用站台

模组仅在为线路新增停靠站时触发，可一次勾选该车站的其他站台作为备用。

添加方式

点击车站或用手柄确认添加时：

  • 未按住触发按键：按原版方式添加停靠站，模组不自动勾选备用站台。
  • 按住触发按键：添加停靠站时，模组会自动勾选该车站的其他站台作为备用。

触发按键

  • 键鼠：默认使用 Ctrl，可在模组选项的「键盘触发按键」中改为 Alt。
  • 手柄：PlayStation 使用 R1，Xbox 使用 RB。按键固定，不可配置，也不受键盘选项影响。

R1／RB 保留原版新增途经点的功能。添加途经点不会触发备用站台选择。

使用提示

主站台分配、自动货物选择和装载设置仍由原版处理。模组不会在后续编辑时重新勾选你手动取消的备用站台。

若出现路径警告，请检查并取消当前线路无法到达的备用站台。

安装与存档

本模组不依赖其他模组，可在已有存档中启用。移除模组后，已保存的备用站台设置仍会保留。

兼容性提示：从含 Shift 选项的旧版升级后，键盘触发按键默认恢复为 Ctrl；若原先使用 Alt，请在模组选项中重新选择 Alt。

English · Auto Alternative Terminals

Automatically select alternative terminals when adding a station stop to a line. The mod only acts on the stop being added.

Adding a stop

When you click a station or confirm it with a controller:

  • Without holding the activation key or button: The stop is added as in the base game. The mod does not automatically select alternative terminals.
  • While holding the activation key or button: The stop is added and the mod automatically selects the station's other terminals as alternatives.

Activation controls

  • Keyboard and mouse: Ctrl by default. To use Alt, select it under Keyboard activation key in the mod options.
  • Controller: R1 on PlayStation or RB on Xbox. This button cannot be changed and is unaffected by the keyboard option.

R1 / RB retains its usual function for adding waypoints. Adding a waypoint does not trigger alternative terminal selection.

Usage notes

The game still handles primary terminal assignment, automatic cargo selection and loading settings. During later edits, the mod will not reselect alternatives you have manually deselected.

If a route warning appears, check the alternative terminals and deselect any that the line cannot reach.

Installation and saves

No other mods are required. You can enable this mod in existing saves. Saved alternative terminal settings remain after removing the mod.

Compatibility note: When upgrading from a version that offered Shift, the keyboard activation key defaults to Ctrl. If you previously used Alt, select Alt again in the mod options.

Français · Sélection automatique des terminaux alternatifs

Sélectionnez automatiquement les terminaux alternatifs lors de l'ajout d'un arrêt à une ligne. Le mod agit uniquement sur l'arrêt que vous ajoutez.

Ajouter un arrêt

Lorsque vous cliquez sur une station ou la validez à la manette :

  • Sans maintenir la touche ou le bouton d'activation : L'arrêt est ajouté comme dans le jeu de base. Le mod ne sélectionne pas automatiquement de terminaux alternatifs.
  • En maintenant la touche ou le bouton d'activation : L'arrêt est ajouté et le mod sélectionne automatiquement les autres terminaux de la station comme alternatives.

Commandes d'activation

  • Clavier et souris : Ctrl par défaut. Pour utiliser Alt, modifiez l'option Touche d'activation au clavier dans les options du mod.
  • Manette : R1 sur PlayStation ou RB sur Xbox. Ce bouton n'est pas configurable et ne dépend pas du réglage du clavier.

R1 / RB conserve sa fonction habituelle d'ajout de points de passage. L'ajout d'un point de passage ne déclenche pas la sélection des terminaux alternatifs.

Conseils d'utilisation

Le jeu continue de choisir le terminal principal, de sélectionner automatiquement les marchandises et de gérer les paramètres de chargement. Lors des modifications suivantes, le mod ne sélectionne pas à nouveau les terminaux alternatifs que vous avez désélectionnés manuellement.

Si un avertissement d'itinéraire apparaît, vérifiez les terminaux alternatifs et désélectionnez ceux que la ligne ne peut pas atteindre.

Installation et sauvegardes

Aucun autre mod n'est nécessaire. Vous pouvez activer ce mod dans une partie déjà commencée. Les paramètres des terminaux alternatifs enregistrés dans la sauvegarde sont conservés après sa suppression.

Note de compatibilité : Après une mise à jour depuis une version qui proposait Maj (Shift), la touche d'activation au clavier revient à Ctrl par défaut. Si vous utilisiez Alt, choisissez de nouveau Alt dans les options du mod.
